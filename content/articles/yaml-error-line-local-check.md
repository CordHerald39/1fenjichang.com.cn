## 报错行往往只是发现问题的位置

导入时出现 YAML 行号错误，说明解析过程遇到了结构问题，不足以证明节点失效。只在本机查看配置副本，先记下报错的行号、列号和原文。不要把带订阅地址、密码或 UUID 的全文贴到在线校验站。

## 从上一层结构向下查

打开能显示空格与制表符的纯文本编辑器。缩进使用空格，检查同级字段是否齐平；不要直接把全部行往左移。列表项应属于正确父字段，冒号后需要值的位置也要检查。报错指向某一行时，连同前面几行一起看，前一行未闭合的引号可能影响下一行。

~~~yaml
# 结构示意，不是可连接的服务配置
proxy-groups:
  - name: 示例选择
    type: select
    proxies:
      - DIRECT
~~~

这里的 proxies 是代理组的子字段。如果它被移到顶层，文件可能仍有合法 YAML 语法，却不再表达相同配置。

## 再查容易被忽略的字符

复制网页代码可能带入中文冒号、弯引号或不可见字符。含冒号加空格、井号等字符的名称，应按 YAML 规则使用引号。不要全局替换整份配置中的字符，URL 和密码可能因此被破坏。重复出现的同名映射键也要处理，不能依赖不同解析器选择“第一份”还是“最后一份”。

## 格式通过后，继续核对内核

YAML 合法不代表客户端支持字段。用当前客户端自带的配置检查，区分“语法错误”“未知字段”“策略组引用不存在”。如果原始订阅可导入、手工修改版失败，先恢复原版，再通过客户端支持的扩展功能逐项加入修改。

解决后重启或重载一次配置，确认策略组和节点列表都存在；只保存脱敏的错误行与修改说明。订阅操作见[导入订阅](/tutorials/import-subscription/)。

## 原始资料

[YAML 1.2.2 规范](https://yaml.org/spec/1.2.2/)规定缩进与映射语法；[mihomo 代理组文档](https://wiki.metacubex.one/config/proxy-groups/)用于核对结构。示例只解释格式，不代表一分机场的服务配置。
